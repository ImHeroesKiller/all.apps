## Pemasangan

Unduh APK, lalu izinkan pemasangan dari sumber tersebut di Android. Pembaruan dengan package ID dan sertifikat sama dapat dipasang tanpa menghapus aplikasi. Android biasanya menolak downgrade ke versionCode lebih rendah; versi lama disediakan sebagai arsip.

## Status v1.3.3

Perbaikan render jawaban, duplikasi sumber, pembacaan artikel, konteks lanjutan, klarifikasi nama ambigu dan gambar yang sesuai sumber. Validasi lokal: 157 tes unit dan 19 tes emulator lulus, delapan tes live opsional dilewati pada suite gabungan; lima tes live terpisah lulus. Upgrade v1.3.2 ke v1.3.3 mempertahankan login di emulator. CI GitHub tidak dapat dimulai karena batas billing/spending akun. Pengujian perangkat fisik tetap diperlukan; hasil research tidak menjamin setiap klaim benar.
